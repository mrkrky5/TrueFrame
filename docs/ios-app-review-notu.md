**English**

True Frame is an educational app (App Store listing name: True Frame Media) that explores the real history behind games, films, and series.

- **No login required.** Reading progress and saved items are stored only on the device (local storage).
- **Editorial content is bundled** in the app (JSON). No account or login.
- **External source links** open in the system browser (Safari).
- **Optional banner ads** on Explore (iOS AdMob). No in-app purchases, no user-generated content.

**Suggested demo path (no account):**
1. Complete onboarding → Start Exploring  
2. Open “Today’s Reality Check” on Home  
3. Explore tab → search “Shōgun” → open a media dossier → read one card  
4. Save to Library → verify under Library tab  
5. Optional: Routes tab → open a learning journey  

**Support:** https://trueframe.app/tr/support  
**Privacy:** https://trueframe.app/tr/privacy
